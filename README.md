# Ritesh Portfolio Website

A personal portfolio website built with HTML and CSS. The website includes pages for the home section, about information, skills, projects, and contact details.

## Pages

- `Home.html` — Introduction and portfolio overview
- `About.html` — About section
- `Skills.html` — Skills section
- `Projects.html` — Projects section
- `Contact.html` — Contact information and message form

## Project Structure

```text
portfolio/
├── Home.html
├── About.html
├── Skills.html
├── Projects.html
├── Contact.html
├── css/
│   └── style.css
└── Img/
    ├── images and icons
    └── Resume.pdf
```

## Technologies Used

- HTML
- CSS

## How to Run

1. Download or clone this repository.
2. Open the `portfolio` folder.
3. Open `Home.html` in your web browser.

## Customization

- Edit the HTML files to update page content.
- Edit `css/style.css` to change the website's design and styling.
- Replace or add files in the `Img` folder to update images and icons.
